Privacy Policy — Container Jump

Last updated: 1 November 2026 · Application ID: com.biayko.containerjump · Türkçe

Overview

Container Jump ("the game") is a 2D platform game set in a toy-sized container port. It works fully offline and does not require an account. This version is free, shows no ads and has no in-app purchases.

Data we collect

None. Your game progress (unlocked levels, stars, coins, best times, costumes) and your settings (language, sound, vibration, control layout) are stored only on your device and are never sent to us or to anyone else. Uninstalling the game deletes them.

The game contains no analytics, crash-reporting or advertising SDKs, and we have no user database — there is nothing for us to look up, export or delete on request.

Network

The game makes one network request of its own: when it starts, it downloads a small public file (appVersion.json) from this website, arodat.github.io, to check whether the installed version still works or a required update is available. The request carries no account, identifier or game data. Like any website, the hosting service (GitHub Pages, run by GitHub, Inc.) receives your device's IP address to deliver the file; we do not receive or keep it. Without a connection the check is simply skipped and the game works normally.

Permissions

The game uses vibration for short touch feedback (you can turn it off in Settings) and plays sound effects. It does not access your camera, microphone, location, contacts, photos or files.

Children

The game does not collect personal information from anyone, including children.

Future versions

A later version may offer optional rewarded ads or a one-time purchase. If it does, this policy will be updated before that version is released, describing exactly what those providers process.

Changes

We may update this policy as the game evolves. The "Last updated" date above shows the latest revision.
